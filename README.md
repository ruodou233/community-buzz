# community-buzz

想知道一个东西到底好不好用，去看看长期用它的人怎么说。`community-buzz` 帮 Agent 从知乎、B站、什么值得买、V2EX、NGA、贴吧和垂直论坛里找有内容的讨论，把具体体验、比较和争议捞出来，附上值得读的原帖。产品口碑、软件体验、技术路线的实践反馈，都可以这样查。

## 可以去社区里找什么

- **买之前看看口碑**：“帮我看看社区怎么评价这款耳机。”除了好不好听，还可以找佩戴、连接和用了几个月后的反馈，把反复被提到的优缺点摆出来。
- **两个候选拿不定主意**：“A 和 B 哪个真实口碑更好？”优先找都用过的人，看看差异发生在什么场景，哪些是产品差别，哪些只是个人喜好。
- **想知道长期用下来怎么样**：“这个产品论坛里有人长期用过吗？”从维修、更新、续费和弃用经历里，找发布时的评测还看不到的事情。
- **了解从业者实际怎么做**：“这个技术方案大家真在用吗，踩过哪些坑？”把实践经验和主要争议放在一起，方便你继续追问和判断。

## 筛选方式

- 新采的帖子、回答、视频、评论或回复，只有对象自身原生正向计数不少于 10 才能成为最终证据；帖子和评论分别计算。
- 通过门槛后，只提取具体体验、比较、长期反馈和明确争议。
- 同一内容的转载和重复发布合并，不累加点赞。

每条结果都会解释它在说什么、为什么值得看，并附来源、时间和采集时的正向计数，而不是只发标题。
